# 📖 1. Introduction

## What is `@Bean`?

`@Bean` is used to **create and register an object (Bean)** inside the Spring IoC Container.

When Spring starts, it calls every method annotated with `@Bean` and stores the returned object as a bean.

---

## Simple Definition

> `@Bean` is used to create a Spring-managed object.

---

## Interview Definition

> `@Bean` is a method-level annotation used inside a `@Configuration` class to declare and register a bean in the Spring IoC Container.

---

# 🤔 Why Do We Need `@Bean`?

Earlier we created beans using XML.

```xml
<bean id="student"
      class="com.springcore.javaconfig.Student"/>
```

Now XML is removed.

So how will Spring know what object to create?

Answer:

```java
@Bean
```

# 📚 What Does `@Bean` Do?

Suppose we write

```java
@Bean
public Student student() {

    return new Student();

}
```

Spring executes

```java
Student s = new Student();
```

Stores it inside the IoC Container.

Later,

```java
context.getBean("student");
```

returns the same object (Singleton by default).

# Multiple Beans

```java

public class AppConfig {

    @Bean
    public Student student() {

        return new Student();

    }

    @Bean
    public Address address() {

        return new Address();

    }

}
```

Spring creates

```

```

# Dependency Between Beans

Suppose

Student has an Address.

```java
public class Student {

    private Address address;

    public Student(Address address) {

        this.address = address;

    }

}
```

Configuration

```java
@Configuration
public class AppConfig {

    @Bean
    public Address address() {

        return new Address();

    }

    @Bean
    public Student student() {

        return new Student(address());

    }

}
```

Notice

```java
address()
```

returns the Spring-managed `Address` bean.

Spring ensures the dependency is injected correctly.

# Common Mistakes

## ❌ Forgetting `@Configuration`

```java
public class AppConfig
```

Spring won't recognise it as a configuration class.

---

## ❌ Forgetting `@Bean`

```java
public Student student() {

    return new Student();

}
```

Spring will never register this object as a bean.

---

## ❌ Wrong Bean Name

```java
context.getBean("studentBean");
```

when method name is

```java
student()
```

Results in

```
NoSuchBeanDefinitionException
```

# Interview Questions

### Q1. What is `@Bean`?

It creates and registers an object as a Spring bean.

---

### Q2. Where is `@Bean` used?

Inside a class annotated with `@Configuration`.

---

### Q3. What is the default bean name?

The **method name**.

Example:

```java
@Bean
public Student student()
```

Bean name:

```
student
```

---

### Q4. Can we give a custom bean name?

Yes.

```java
@Bean("studentBean")
```

---

### Q5. What is the default scope of a bean created using `@Bean`?

**Singleton**.

---

# Best Practices

- ✅ Keep `@Bean` methods small and focused.
    
- ✅ Use meaningful method names (`student()`, `dataSource()`, `entityManager()`).
    
- ✅ Group related beans into dedicated configuration classes (e.g., `DatabaseConfig`, `SecurityConfig`).
