Implementing Lifecycle Methods Using XML

means telling Spring to call one method when a bean is

created

and another method when the bean is

destroyed

.

### 1. What is it?

In Spring, every bean (object managed by Spring) has a lifecycle:

Bean Created

Initialized

Used

Destroyed

Using XML, we can define:

- init-method → called after bean creation
    
- destroy-method → called before bean destruction
    

### 2. Why was it introduced?

Imagine a bean that:

- Opens a database connection
    
- Reads a file
    
- Starts a thread
    
- Loads cache data
    

These resources must be cleaned when the application stops.

Instead of manually calling cleanup methods, Spring does it automatically.

### 3. Real-Life Analogy

### Car Example

Before driving

### Start Engine

### Drive

### Stop Engine

Destroy Method

Spring beans behave in the same way.

### 4. XML Syntax

XML

```xml
<bean
    id="student"
    class="com.springcore.lifecycle.Student"
    init-method="init"
    destroy-method="destroy">

    <property name="name" value="Musaib"/>

</bean>
```

### 5. Complete Example

### Student.java

Java

```java
package com.springcore.lifecycle;

public class Student {

    private String name;

    // Constructor
    public Student() {
        System.out.println("1. Constructor Called");
    }

    // Setter Injection
    public void setName(String name) {
        System.out.println("2. Setter Injection Called");
        this.name = name;
    }

    // Initialization Method
    public void init() {
        System.out.println("3. Initialization Method Called");
    }

    // Destroy Method
    public void destroy() {
        System.out.println("5. Destroy Method Called");
    }

    @Override
    public String toString() {
        return "4. Student Name : " + name;
    }
}
```

### 6. XML Configuration

### lifecycleconfig.xml

XML

```xml
<?xml version="1.0" encoding="UTF-8"?>

<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="
       http://www.springframework.org/schema/beans
       https://www.springframework.org/schema/beans/spring-beans.xsd">

    <bean id="student"
          class="com.springcore.lifecycle.Student"
          init-method="init"
          destroy-method="destroy">

        <property name="name" value="Musaib"/>

    </bean>

</beans>
```

### 7. Test Class

Java

```java
package com.springcore.lifecycle;

import org.springframework.context.support.AbstractApplicationContext;
import org.springframework.context.support.ClassPathXmlApplicationContext;

public class Test {

    public static void main(String[] args) {

        AbstractApplicationContext context =
                new ClassPathXmlApplicationContext("lifecycleconfig.xml");

        Student student = (Student) context.getBean("student");

        System.out.println(student);

        // Important for destroy-method
        context.registerShutdownHook();
    }
}
```

### 10. Why This Order?

|Step|Action|
|---|---|
|1|Constructor creates object|
|2|Setter injects values|
|3|init()executes|
|4|Application uses bean|
|5|destroy()executes during shutdown|

### 11. Important Point: registerShutdownHook()

### Without registerShutdownHook()

Java

```
// destroy() may NOT execute
```

### With registerShutdownHook()

Java

```
context.registerShutdownHook();
// destroy() executes automatically
```

### 13. Common Mistakes

### Mistake 1: Wrong method name

XML

```xml
init-method="inti"   // wrong
```

### Mistake 2: Forgetting shutdown hook

Java

```java
// destroy() not called
```

### Mistake 3: Wrong bean id

Java

```java
context.getBean("student1"); // XML has "student"
```

### 14. Best Practices

- Use init() only for setup work.
    
- Use destroy() only for cleanup work.
    
- Keep lifecycle methods short.
    
- Avoid business logic inside lifecycle methods.
    
- Always close the container properly.
    

### 15. Interview Questions

Q1. What is init-method?

Frequently Asked

A method executed automatically after bean creation and dependency injection.

Q2. What is destroy-method?

Frequently Asked

A method executed automatically before bean destruction.

Q3. Why is init-method called after setter injection?

Important

Because the bean must have all required dependencies before initialization logic runs.

Q4. Does destroy-method run for prototype beans?

Interview Favorite

No. Spring does not automatically call destroy-method for prototype beans.

Q5. Which executes first?

Basic

Constructor → Setter Injection → init-method
