# Step 1: Computer.java

```java
package com.springcore.beanscope;

public class Computer {

    private String brand;

    public Computer() {
        System.out.println("Computer Bean Created...");
    }

    public String getBrand() {
        return brand;
    }

    public void setBrand(String brand) {
        this.brand = brand;
    }

    public void display() {
        System.out.println("Brand : " + brand);
    }

}
```

---

# Step 2: beanscopeconfig.xml (Singleton)

```xml
<?xml version="1.0" encoding="UTF-8"?>

<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"

       xsi:schemaLocation="
       http://www.springframework.org/schema/beans
       https://www.springframework.org/schema/beans/spring-beans.xsd">

    <bean id="computer"
          class="com.springcore.beanscope.Computer"
          scope="singleton">

        <property name="brand" value="Dell"/>

    </bean>

</beans>
```

# Step 3: Test.java

```java
package com.springcore.beanscope;

import org.springframework.context.ApplicationContext;
import org.springframework.context.support.ClassPathXmlApplicationContext;

public class Test {

    public static void main(String[] args) {

        ApplicationContext context =
                new ClassPathXmlApplicationContext("beanscopeconfig.xml");

        Computer c1 = context.getBean("computer", Computer.class);

        Computer c2 = context.getBean("computer", Computer.class);

        c1.display();
        c2.display();

        System.out.println();

        System.out.println("HashCode of c1 : " + c1.hashCode());

        System.out.println("HashCode of c2 : " + c2.hashCode());

        System.out.println();

        System.out.println("Same Object ? " + (c1 == c2));

    }

}
```

# Comparison

|Singleton|Prototype|
|---|---|
|One Object|New Object Every Time|
|Default Scope|Explicitly Configure|
|Shared Object|Separate Objects|
|Less Memory|More Memory|
|Faster|Slightly Slower|

# Interview Questions

### Q1. What is the default bean scope in Spring?

**Answer:** `singleton`

---

### Q2. How many objects are created in Singleton?

**Answer:** Only one object per Spring IoC container.

---

### Q3. How many objects are created in Prototype?

**Answer:** A new object is created every time `getBean()` is called.

---

### Q4. How do you verify the bean scope?

**Answer:** Compare:

- `hashCode()`
    
- `==` operator
    

---

### Q5. Which scope is used most often?

**Answer:** `singleton`, because service, repository, and controller beans are usually shared across the application.

---

# Best Practices

- ✅ Use **Singleton** for stateless beans like services, repositories, and controllers.
    
- ✅ Use **Prototype** when each request needs an independent object with its own state.
    
- ✅ Avoid storing user-specific data in singleton beans, as they are shared by all users.
    

---

# Quick Revision

- ✔ `singleton` → One bean instance shared by the container.
    
- ✔ `prototype` → New bean instance for every `getBean()` call.
    
- ✔ Verify using `hashCode()` or `==`.
    
- ✔ Default scope is `singleton`.
