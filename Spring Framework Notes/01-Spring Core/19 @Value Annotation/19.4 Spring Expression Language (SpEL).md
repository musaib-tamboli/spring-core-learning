# 📖 What is SpEL?

**SpEL** stands for **Spring Expression Language**.

It is a powerful expression language provided by Spring that allows you to:

- Perform calculations
    
- Use mathematical operations
    
- Read system properties
    
- Call methods
    
- Access bean properties
    
- Make logical decisions
    

---

## Simple Definition

> SpEL allows Spring to evaluate expressions at runtime and inject the result into a bean.

---

## One-Line Definition

> **SpEL = Java-like expressions inside Spring annotations.**

---

# 🤔 Why Was SpEL Introduced?

Imagine you want:

```java
private double pi = 3.1415926535;
```

Instead of writing:

```java
@Value("3.1415926535")
private double pi;
```

Spring can calculate it automatically:

```java
@Value("#{T(java.lang.Math).PI}")
private double pi;
```

No hardcoded value.

# Step 1 : Demo.java

```java
package com.springcore.spel;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

@Component
public class Demo {

    @Value("#{10 + 20}")
    private int sum;

    @Value("#{50 - 15}")
    private int subtraction;

    @Value("#{8 * 5}")
    private int multiplication;

    @Value("#{20 / 4}")
    private int division;

    @Value("#{20 % 3}")
    private int remainder;

    public void display() {

        System.out.println("Sum            : " + sum);
        System.out.println("Subtraction    : " + subtraction);
        System.out.println("Multiplication : " + multiplication);
        System.out.println("Division       : " + division);
        System.out.println("Remainder      : " + remainder);

    }

}
```

---

```text
Subtraction    : 35
Multiplication : 40
Division       : 5
Remainder      : 2
```

# Real Company Usage

SpEL is used for:

- Dynamic configuration
    
- Feature toggles
    
- Conditional bean creation
    
- Security rules (Spring Security)
    
- Scheduling expressions
    
- Cache key generation
    
- Bean property calculations
    

However, for **basic Spring Boot development**, you'll mostly use `${}` with `application.properties`. SpEL is powerful, but it's typically used only when you need dynamic behavior.
