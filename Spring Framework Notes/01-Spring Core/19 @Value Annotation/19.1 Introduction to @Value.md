# 📖 1. What is `@Value`?

`@Value` is an annotation used to **inject simple values into Spring-managed Beans**.

These values can come from:

- Hardcoded values
    
- `.properties` files
    
- Environment variables
    
- System properties
    
- Spring Expression Language (SpEL)
    

---

## Simple Definition

> `@Value` injects data (values) into variables of a Spring Bean.

---

## One-Line Definition

> **`@Value` = Value Injection**

---

## Interview Definition

> `@Value` is a Spring annotation used to inject primitive values, Strings, configuration properties, environment variables, or SpEL expressions into Spring-managed beans.

---

# 🤔 Why Was `@Value` Introduced?

Imagine you write:

```java
@Component
public class Mobile {

    private String brand = "Samsung";
    private int ram = 8;
}
```

This works.

But tomorrow:

- Brand changes to Apple
    
- RAM changes to 12
    
- Price changes to ₹75,000
    

You must **edit the Java source code** and recompile the application.

This is not a good design.

---

# Solution

Instead of hardcoding values inside the class:

```java
@Component
public class Mobile {

    @Value("Samsung")
    private String brand;

    @Value("8")
    private int ram;

}
```

Spring injects the values automatically.

---

# 🔍 Why Do We Need `@Value`?

Without `@Value`

```java
private String brand = "Samsung";
```

Problems:

- Hardcoded values
    
- Difficult to maintain
    
- Not configurable
    
- Every change requires code modification
    

---

With `@Value`

```java
@Value("Samsung")
private String brand;
```

Later you can replace `"Samsung"` with:

```properties
mobile.brand=Samsung
```

without changing Java code.

This is the real power of `@Value`.

# 🧩 `@Autowired` vs `@Value`

This is one of the **most frequently asked interview questions**.

|Feature|`@Autowired`|`@Value`|
|---|---|---|
|Purpose|Inject another Spring Bean|Inject a simple value|
|Injects|Objects|Primitive types, String, properties|
|Example|`CPU cpu`|`"Samsung"`|
|Used For|Dependency Injection|Property Injection|

### Example

```java
@Autowired
private CPU cpu;
```

Spring injects a **CPU object**.

---

```java
@Value("Samsung")
private String brand;
```

Spring injects the **String "Samsung"**.

# 🏗 Behind the Scenes

Think of Spring doing something like this internally:

```java
Mobile mobile = new Mobile();

mobile.brand = "Samsung";
```

You don't write this code.

Spring performs it using **reflection**.

> **Reflection** is a Java feature that allows a program to inspect and modify classes, fields, and methods at runtime.

# 📌 Where Can `@Value` Be Used?

## 1. Field Injection

```java
@Value("Samsung")
private String brand;
```

✅ Most common.

---

## 2. Constructor Injection

```java
public Mobile(@Value("Samsung") String brand) {

    this.brand = brand;

}
```

---

## 3. Setter Injection

```java
@Value("Samsung")
public void setBrand(String brand) {

    this.brand = brand;

}
```

# 🌍 Real Company Example

Imagine an e-commerce application.

Instead of writing:

```java
double tax = 18;
```

Developers use:

```properties
tax.rate=18
```

Then:

```java
@Value("${tax.rate}")
private double taxRate;
```

Now changing the tax requires updating only the configuration file, not the Java code.

# ❌ Common Mistakes

### Mistake 1

Using `@Value` in a normal Java object.

```java
public class Mobile {

    @Value("Samsung")
    private String brand;

}
```

❌ Doesn't work.

Because Spring never creates this object.

---

### Correct

```java
@Component
public class Mobile {

    @Value("Samsung")
    private String brand;

}
```

---

### Mistake 2

Creating the object manually.

```java
Mobile mobile = new Mobile();
```

Spring cannot inject values into manually created objects.

Always get the bean from the container:

```java
Mobile mobile = context.getBean(Mobile.class);
```

---

### Mistake 3

Trying to inject a bean using `@Value`.

```java
@Value
private CPU cpu;
```

❌ Wrong.

Use:

```java
@Autowired
private CPU cpu;
```

# 🎤 Interview Questions

### Q1. What is `@Value`?

It injects primitive values, Strings, configuration properties, or expressions into Spring Beans.

---

### Q2. Can `@Value` inject objects?

No.

For object injection, use `@Autowired`.

---

### Q3. Can `@Value` read values from a properties file?

Yes.

Example:

```java
@Value("${server.port}")
private int port;
```

---

### Q4. Can `@Value` inject primitive types?

Yes.

It supports:

- `int`
    
- `long`
    
- `float`
    
- `double`
    
- `boolean`
    
- `char`
    
- `String`

# 📝 Revision Notes

- ✅ `@Value` is used for **Property Injection**.
    
- ✅ It injects **simple values**, not objects.
    
- ✅ It works only on **Spring-managed Beans**.
    
- ✅ Values can come from hardcoded strings, properties files, environment variables, or SpEL.
    
- ✅ Spring uses **reflection** internally to set the values.
