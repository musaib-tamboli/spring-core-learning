# 🌱 Autowiring using `@Autowired` Annotation (Spring Core)

> **Goal:** Learn how Spring performs **automatic dependency injection using annotations** instead of XML.

---

# 📌 1. What is `@Autowired`?

`@Autowired` is a **Spring annotation** that tells the Spring Container:

> **"Find the required bean automatically and inject it here."**

Instead of writing:

```xml
<property name="engine" ref="engine"/>
```

or

```xml
autowire="byType"
```

we simply write:

```java
@Autowired
private Engine engine;
```

Spring injects the `Engine` object automatically.

---

# 🤔 Why was `@Autowired` introduced?

XML configuration becomes very large in enterprise applications.

Example:

```xml
<property name="engine" ref="engine"/>
<property name="battery" ref="battery"/>
<property name="musicSystem" ref="musicSystem"/>
<property name="gps" ref="gps"/>
```

Hundreds of such lines become difficult to maintain.

Instead, Spring introduced annotations.

```java
@Autowired
private Engine engine;

@Autowired
private Battery battery;
```

Cleaner and easier to maintain.

---

# 📖 Real-Life Analogy

Imagine a car factory.

### XML Approach

You tell the worker:

```
Install Engine.

Install Battery.

Install Tyres.
```

Everything is manual.

---

### `@Autowired`

You simply say:

```
Build a Car.
```

The factory automatically installs:

- Engine
    
- Battery
    
- Tyres
    

Exactly the same way, Spring injects dependencies automatically.

# Example

## Engine.java

```java
package com.springcore.autowire.annotation;

public class Engine {

    public Engine() {
        System.out.println("Engine Created");
    }

    @Override
    public String toString() {
        return "Petrol Engine";
    }
}
```

---

## Car.java

```java
package com.springcore.autowire.annotation;

import org.springframework.beans.factory.annotation.Autowired;

public class Car {

    @Autowired
    private Engine engine;

    public Car() {
        System.out.println("Car Created");
    }

    public void start() {
        System.out.println(engine);
        System.out.println("Car Started");
    }
}
```

Notice

```java
@Autowired
private Engine engine;
```

No setter.

No constructor.

Spring injects automatically.

---

## XML Configuration

```xml
<?xml version="1.0" encoding="UTF-8"?>

<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xmlns:context="http://www.springframework.org/schema/context"

       xsi:schemaLocation="
       http://www.springframework.org/schema/beans
       https://www.springframework.org/schema/beans/spring-beans.xsd

       http://www.springframework.org/schema/context
       https://www.springframework.org/schema/context/spring-context.xsd">

    <!-- Enables annotation processing -->
    <context:annotation-config/>

    <bean id="engine"
          class="com.springcore.autowire.annotation.Engine"/>

    <bean id="car"
          class="com.springcore.autowire.annotation.Car"/>

</beans>
```

---

# What is `<context:annotation-config/>`?

This line is **mandatory** when using `@Autowired` with XML.

```xml
<context:annotation-config/>
```

It tells Spring:

> "Look for annotations like `@Autowired` and process them."

Without it,

Spring ignores `@Autowired`.

---

# Types of `@Autowired`

Spring allows three types of dependency injection.

---

# 1️⃣ Field Injection

```java
@Autowired
private Engine engine;
```

Most common.

Spring injects directly into the field.

---

# 2️⃣ Setter Injection

```java
private Engine engine;

@Autowired
public void setEngine(Engine engine) {
    this.engine = engine;
}
```

Spring calls

```
setEngine(engine)
```

automatically.

---

# 3️⃣ Constructor Injection ⭐ (Recommended)

```java
private Engine engine;

@Autowired
public Car(Engine engine) {
    this.engine = engine;
}
```

Spring calls

```
new Car(engine)
```

This is the **recommended** approach in modern Spring applications because:

- Dependencies are mandatory.
    
- Objects become immutable if fields are `final`.
    
- Easier to test.

# Important Annotations Used with `@Autowired`

## 1. `@Autowired`

### Purpose

Automatically injects a dependency.

```java
@Autowired
private Engine engine;
```

---

## 2. `@Qualifier`

### Problem

Suppose there are two Engine beans.

```xml
<bean id="petrolEngine" class="Engine"/>

<bean id="dieselEngine" class="Engine"/>
```

Spring becomes confused.

```
Engine

↓

Which one?
```

Use

```java
@Autowired
@Qualifier("petrolEngine")
private Engine engine;
```

Now Spring injects only

```
petrolEngine
```

---

## 3. `@Primary`

Suppose

```xml
petrolEngine

dieselEngine
```

Both are candidates.

Instead of writing

```java
@Qualifier
```

everywhere,

mark one bean as default.

```java
@Primary
@Component
public class PetrolEngine {
}
```

Whenever Spring finds multiple beans,

it chooses

```
PetrolEngine
```

---

## 4. `@Component`

Marks a class as a Spring Bean.

```java
@Component
public class Engine {
}
```

Instead of writing

```xml
<bean .../>
```

---

## 5. `@ComponentScan`

Searches packages for

```
@Component

@Service

@Repository

@Controller
```

Example

```java
@ComponentScan("com.springcore")
```

---

## 6. `@Service`

Used for Service Layer.

```java
@Service
public class StudentService {
}
```

---

## 7. `@Repository`

Used for DAO or Repository classes.

```java
@Repository
public class StudentRepository {
}
```

---

## 8. `@Controller`

Used in Spring MVC.

```java
@Controller
public class HomeController {
}
```

---

## 9. `@Configuration`

Marks a Java configuration class.

```java
@Configuration
public class AppConfig {
}
```

---

## 10. `@Bean`

Creates a bean manually inside a configuration class.

```java
@Bean
public Engine engine() {
    return new Engine();
}
```

# Comparison

|XML Autowiring|Annotation Autowiring|
|---|---|
|`autowire="byName"`|`@Autowired`|
|`autowire="byType"`|`@Autowired`|
|`<property ref="">`|`@Autowired`|
|XML configuration|Java annotations|
|More XML|Less XML|
|Older style|Modern style|

# Interview Questions

### What is `@Autowired`?

It is a Spring annotation used to automatically inject dependencies into a bean.

---

### Can `@Autowired` be used on?

- ✅ Field
    
- ✅ Setter Method
    
- ✅ Constructor
    

---

### Which injection type is recommended?

✅ Constructor Injection.

---

### What happens if there are two beans of the same type?

Spring throws a **`NoUniqueBeanDefinitionException`** unless you use:

- `@Qualifier`
    
- `@Primary`
    

---

# Revision

✔ `@Autowired` performs automatic dependency injection.

✔ Works by **type** by default.

✔ Can be applied on:

- Field
    
- Setter
    
- Constructor
    

✔ `<context:annotation-config/>` enables annotation processing in XML.

✔ `@Qualifier` resolves ambiguity.

✔ `@Primary` marks the default bean.
