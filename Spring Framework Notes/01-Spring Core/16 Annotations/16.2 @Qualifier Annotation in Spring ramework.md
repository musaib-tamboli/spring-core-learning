# 🌱 `@Qualifier` Annotation in Spring Framework

> **Topic:** `@Qualifier`
> 
> **Prerequisite:** `@Autowired`

---

# 📖 1. Introduction

## What is `@Qualifier`?

`@Qualifier` is a Spring annotation used to **specify which bean should be injected** when **multiple beans of the same type** are available in the Spring IoC Container.

It is always used **along with `@Autowired`**.

---

## Why was it introduced?

Suppose Spring finds **more than one bean** that matches the required type.

Spring becomes confused because it doesn't know **which bean to inject**.

`@Qualifier` removes this confusion by explicitly telling Spring **which bean to use**.

---

## Problem It Solves

Without `@Qualifier`:

```text
Engine Interface
      │
      ├── PetrolEngine
      │
      └── DieselEngine

Car needs Engine
```

Spring asks:

> Which Engine should I inject?

It cannot decide.

---

## One-Line Definition

> **`@Qualifier` tells Spring exactly which bean to inject when multiple beans of the same type exist.**

# 📚 3. Why Do We Need `@Qualifier`?

Suppose we have two beans.

```java
@Component
public class PetrolEngine implements Engine { }
```

```java
@Component
public class DieselEngine implements Engine { }
```

Now the Car class is:

```java
@Autowired
private Engine engine;
```

Spring searches for an `Engine` bean.

It finds:

```text
PetrolEngine

DieselEngine
```

Both match the required type.

Spring throws an exception:

```text
NoUniqueBeanDefinitionException
```

Because it cannot decide which bean to inject.

# 📝 6. Syntax

## Basic Syntax

```java
@Autowired
@Qualifier("beanName")
private Engine engine;
```

---

## Constructor Injection

```java
@Autowired
public Car(@Qualifier("petrolEngine") Engine engine) {

    this.engine = engine;

}
```

---

## Setter Injection

```java
@Autowired
public void setEngine(@Qualifier("petrolEngine") Engine engine) {

    this.engine = engine;

}
```

# 💻 7. Complete Example

## Step 1: Engine Interface

```java
package com.springcore.qualifier;

public interface Engine {

    void start();

}
```

---

## Step 2: PetrolEngine

```java
@Component("petrolEngine")
public class PetrolEngine implements Engine {

    @Override
    public void start() {

        System.out.println("Petrol Engine Started");

    }

}
```

---

## Step 3: DieselEngine

```java
@Component("dieselEngine")
public class DieselEngine implements Engine {

    @Override
    public void start() {

        System.out.println("Diesel Engine Started");

    }

}
```

---

## Step 4: Car

```java
@Component
public class Car {

    @Autowired
    @Qualifier("petrolEngine")
    private Engine engine;

    public void drive() {

        engine.start();

        System.out.println("Car Running");

    }

}
```

---

## Output

```text
Petrol Engine Started

Car Running
```

# 📋 9. Comparison

|`@Autowired`|`@Qualifier`|
|---|---|
|Injects dependency automatically|Selects a specific bean|
|Works by type|Works by bean name|
|Can become ambiguous|Removes ambiguity|
|Used alone when one bean exists|Used when multiple beans exist|

---

# ✅ 10. Advantages

- Removes ambiguity.
    
- Allows multiple implementations of the same interface.
    
- Gives precise control over dependency injection.
    
- Easy to understand and maintain.
    
- Widely used in Spring Boot projects.
    

---

# ❌ 11. Disadvantages

- Bean name must be correct.
    
- Typing the wrong bean name causes an exception.
    
- Hard-coded bean names can make refactoring more difficult.
    

---

# ⚠️ 12. Common Mistakes

### ❌ Forgetting `@Autowired`

```java
@Qualifier("petrolEngine")
private Engine engine;
```

`@Qualifier` alone does not inject the bean.

✔ Correct

```java
@Autowired
@Qualifier("petrolEngine")
private Engine engine;
```

---

### ❌ Wrong Bean Name

```java
@Qualifier("petrol")
```

Bean name is

```text
petrolEngine
```

Spring throws

```text
NoSuchBeanDefinitionException
```

---

### ❌ Using `@Qualifier` When Only One Bean Exists

Not required.

Spring can inject automatically.

# 🎯 14. Interview Questions

### Q1. What is `@Qualifier`?

**Answer:** It specifies which bean Spring should inject when multiple beans of the same type are available.

---

### Q2. Why do we need `@Qualifier`?

**Answer:** To resolve ambiguity caused by multiple beans of the same type.

---

### Q3. Can `@Qualifier` work without `@Autowired`?

**Answer:** No. It is normally used together with `@Autowired`.

---

### Q4. Which exception occurs without `@Qualifier`?

**Answer:**

```text
NoUniqueBeanDefinitionException
```

---

### Q5. Does `@Qualifier` work by bean name or bean type?

**Answer:** It works by **bean name**.

# 📝 16. Quick Revision

- ✅ `@Autowired` injects dependencies by **type**.
    
- ✅ `@Qualifier` selects a bean by **name**.
    
- ✅ Used when multiple beans of the same type exist.
    
- ✅ Prevents `NoUniqueBeanDefinitionException`.
    
- ✅ Commonly used with interfaces having multiple implementations.
